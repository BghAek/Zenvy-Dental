# @zenvy/landing

Public marketing site — Next.js static export (`output: 'export'`), SEO-first, served at `zenvydental.fr` via nginx. 3D hero (React Three Fiber) and pricing arrive in S1-7; routes skeleton in S0-8. No API calls in v1 — signup links into `apps/web`.

Currently a skeleton.

## Commands

```sh
pnpm --filter @zenvy/landing dev
pnpm --filter @zenvy/landing build   # static export to out/
```
