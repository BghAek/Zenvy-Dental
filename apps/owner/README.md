# @zenvy/owner

SaaS-owner ops portal — React + Vite SPA, `SUPER_ADMIN` only. Served at `ops.zenvydental.fr`. Client list, error viewer, onboarding queue, support threads (S4-2). Talks only to `@zenvy/api`.

Currently a skeleton.

## Commands

```sh
pnpm --filter @zenvy/owner dev
pnpm --filter @zenvy/owner build
```
