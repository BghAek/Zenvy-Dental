# @zenvy/web

Dentist dashboard — React + Vite SPA (auth required). Served at `app.zenvydental.fr`. Talks only to `@zenvy/api`; types and schemas come from `@zenvy/shared`. All user-visible strings in French.

Currently a skeleton — design system arrives with S0-7, first screens with S1-4/S1-5.

## Commands

```sh
pnpm --filter @zenvy/web dev
pnpm --filter @zenvy/web build
```
