# @zenvy/shared

Shared contracts between the API and the frontends: API types, Zod schemas, constants, enums. Contract-first rule: schemas land here (plus `docs/api/`) **before** either side implements. See `docs/03-api-conventions.md`.

Currently a skeleton — foundations arrive with task S0-6.

## Commands

```sh
pnpm --filter @zenvy/shared build
```
