## What
Implement S2-6: Web appointments pages for the dashboard app.

## Why & decisions
- Built TanStack Query hooks in `appointments.ts`.
- Added `AppointmentListPage.tsx` featuring a toggle between a paginated List view and a lightweight CSS Grid-based Calendar-lite week view.
- Built a reusable `AppointmentForm.tsx` using `react-hook-form` and `@zenvy/shared` validation schemas to power `AppointmentCreatePage.tsx` and `AppointmentEditPage.tsx`.
- Integrated `AppointmentReminderList.tsx` in the detail and edit views to surface the lifecycle events of appointment reminders.
- Used French UI text exclusively as mandated.

## How to test
1. Run the local API and frontend with `pnpm build` or `pnpm dev`.
2. Navigate to "Rendez-vous" in the sidebar.
3. Test creating a new appointment with an existing patient.
4. Verify the appointment shows up in the List and Calendar-lite weekly view.
5. Click "Détails" to view the appointment, edit it, and verify the Reminders status displays.
