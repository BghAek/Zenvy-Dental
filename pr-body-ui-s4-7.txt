## What
Implemented S4-7 copy polish audit tasks for the design system (`Packages/UI`).
- Updated `--accent` in `theme.css` to fix the red hover flash (R1).
- Added `--success`, `--info`, `--warning` tokens (R3) in `theme.css` and `tailwind.config.ts`.
- Added `cursor-pointer` to `button.tsx` base.
- Created accessible native `Dialog` and `ConfirmDialog` components in `@zenvy/ui`.

## Why & decisions
These changes address root causes (R1, R3) and design-system drift noted in `docs/reviews/s4-7-copy-polish.md`.
Decision: Implemented `Dialog` and `ConfirmDialog` using native HTML `<dialog>` elements to maintain standard accessibility (focus trap, Escape to close, backdrop click) without introducing new third-party dependencies as requested.
