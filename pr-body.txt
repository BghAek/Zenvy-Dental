## What
Implemented task S1-5: Web dashboard shell including a sidebar navigation, top header, empty states, error boundary, and loading patterns, completely adhering to the design system (Slate colors, minimalist flat UI, Inter/DM Sans typography style).

## Why & decisions
- Built `DashboardLayout` utilizing `react-router-dom`'s `<Outlet>` for wrapping all authenticated routes.
- Abstracted `EmptyState` and `Spinner` components into `@zenvy/ui` so they can be reused across apps (web, owner, etc.).
- `ErrorBoundary` implemented as a class component to gracefully catch rendering issues and present a friendly French fallback UI.
- S1-5 sprint plan status marked as 🟨.

## How to test
1. Run `pnpm dev` inside `apps/web`.
2. Navigate to `http://localhost:5173/` and explore the different sidebar links (`/`, `/inbox`, `/patients`, `/appointments`, `/settings`).
3. You should see the `PlaceholderPage` components wrapped in the new dashboard layout.
4. Try injecting a runtime error inside a page to observe the `ErrorBoundary` taking over.
